# Limitation Screenshots

Place your screenshot images in this directory. The Help Panel will display them alongside each Known Limitation.

## Expected Files

| Filename | Limitation |
|----------|-----------|
| `1-isolation.png` | Docker container isolation from host machine |
| `2-filesystem.png` | File changes scoped to container filesystem |
| `3-networking.png` | Network behavior differences (port forwarding) |
| `4-gui-tools.png` | Native/GUI tools not working in container |
| `5-performance.png` | Performance and timing variations |
| `6-hot-reload.png` | Hot reloading / file watching issues |
| `7-auth.png` | Git credentials / SSH keys unavailable |
| `8-disk-space.png` | Limited container disk space |
| `9-timeout.png` | Container stopped/reset due to inactivity |
| `10-disconnect.png` | Terminal session disconnection |

## Guidelines

- Use PNG or JPG format
- Recommended width: 800-1200px
- Keep file size under 200KB per image for fast loading
- Screenshots should clearly illustrate the limitation described in the Help Panel
